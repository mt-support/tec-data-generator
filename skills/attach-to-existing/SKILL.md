# Attach to existing content

```bash
wp tec-data-generator add-rsvp <event_id> --quantity=5
wp tec-data-generator add-tickets <event_id> --quantity=5
wp tec-data-generator add-attendees <ticket_id> --quantity=10
```

## Safety

- Targets existing content (generated by this tool or not) — no new
  containers created.
- `add-tickets` creates paid tickets via the event's provider, not RSVP.
  `0 tickets added` on an RSVP-provider event is expected, not an error.
- This is the only paid-ticket path besides `--ticket-type=paid`; keep it
  confined here.

## Verify

Command output reports counts added. Spot-check the event/ticket in wp-admin.
